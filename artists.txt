# ==============================================================================
# БАЗА ДАННЫХ И ВЕРИФИКАЦИЯ АРТИСТОВ ouMusic
# ==============================================================================
# Формат записи (через дефис с пробелами):
# ник_артиста - ссылка_на_аватарку - ссылка_на_баннер - статус_верификации(1_или_0) - побед_в_номинации_артист_месяца(число)
#
# Описание каждой переменной:
# 1. ник_артиста: Имя исполнителя (совпадает с тегом artist в треке, регистр не важен)
# 2. ссылка_на_аватарку: Относительный путь к файлу (например: assets/oumusic.png) или URL
# 3. ссылка_на_баннер: Картинка для фона/шапки страницы артиста (assets/... или URL)
# 4. статус_верификации: 1 — официальный верифицированный артист (фиолетовая галочка с нотой), 0 — обычный
# 5. побед_в_номинации_артист_месяца: Число побед/кубков в номинации «Артист месяца» (отображается в профиле с золотым кубком)
#
# Примеры добавления артистов:
# oulan1 - assets/oumusic.png - assets/oumusic.png - 1 - 3
# M-Core - assets/oumusic.png - assets/oumusic.png - 1 - 5
# Серега Пират - assets/oumusic.png - assets/oumusic.png - 1 - 2
# ==============================================================================
