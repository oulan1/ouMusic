Архитектура движка M-Core

M-Core (Music Core) — это проприетарный высокопроизводительный клиентский движок воспроизведения и обработки звука на базе гибридной цепочки <audio> и Web Audio API.


1. Гибридный звуковой граф: В качестве источника используется нативный потоковый тег с отключенной коррекцией высоты тона (preservesPitch = false), заведенный в Web Audio API через MediaElementAudioSourceNode. Это обеспечивает 100% работу в фоне и островках iOS/Android, а также натуральный эффект Slowed / Nightcore.


2. Vocal Remover BETA: Узел разделения стереоканалов с противофазным вычитанием вокала (L - R) и параллельным НЧ-фильтром 200 Гц для сохранения плотности баса.


3. Формат контейнера .oump3: ZIP-архив с предварительным сохранением header.json (с обложкой thumbBase64) в первых 64 КБ без сжатия (метод STORE). Это позволяет клиенту мгновенно извлекать обложку и метаданные через Range-запрос без выкачивания всего аудиофайла.
